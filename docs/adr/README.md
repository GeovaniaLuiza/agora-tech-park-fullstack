# Registros de Decisões Arquiteturais

Um Architecture Decision Record (ADR) registra uma decisão arquitetural relevante, seu contexto, suas consequências e as evidências que demonstram sua adoção.

Os registros deste diretório documentam decisões já adotadas e comprovadas no sistema Agora Tech Park Fullstack. Eles não descrevem funcionalidades planejadas nem substituem a documentação operacional.
